# dusktreader's toolbox

![toolbox-icon](https://raw.githubusercontent.com/dusktreader/toolbox/main/docs/images/toolbox-icon.png)

A static site that catalogs all of Tucker Beck's open-source projects, organized by language and type. The site is
built with [Zensical](https://zensical.dev) and hosted on GitHub Pages.

View the site here: [tools.dusktreader.dev](https://tools.dusktreader.dev)


## What's here

The toolbox groups projects into categories:

- libraries
- CLI tools
- MkDocs plugins
- templates
- applications

Each project listing is generated by pulling live metadata from PyPI and GitHub (version, release date, release count)
as well as links to the repo, package index, and docs site where applicable.

A YAML registry (`projects.yaml`) is the single source of truth for which projects appear and how they're categorized.
The `toolbox refresh` command reads that registry, hits the APIs, and injects the results into the markdown files
between comment anchors.


## Setup

```
uv sync
```


## Usage

Refresh all project metadata, rebuild the site, and start it running on a local webserver (on port 12000):

```
make refresh
make site
```
