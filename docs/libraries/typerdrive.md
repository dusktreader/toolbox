## Super-quick Start

Requires: Python 3.12 to 3.14

Install through pip:

```bash
pip install typerdrive
```

## Demo

To see the features in action, you can run the demo in an isolated environment with `uv`:

```
uvx --from=typerdrive[demo] typerdrive-demo
```
