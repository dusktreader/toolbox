Have a peek into my toolbox! There's a bunch of stuff in here: libraries, CLI tools, MkDocs plugins, project templates,
and a few standalone applications. Most of these started as solutions to problems I kept running into. A pattern shows
up in two or three projects, the copy-pasting gets old, and eventually it earns its own package. A few things just
seemed fun to make.

Everything here is open source and actively maintained (some more actively than others). If something looks useful,
try it out! If something looks broken, please file an issue.

Browse by category below, or jump straight to the highlights.
